## ✅ IN — 7일 안에 반드시 만든다

### 화면 5개
| # | 화면 | 핵심 기능 |
|---|---|---|
| 1 | **월간 캘린더** (메인) | 날짜별 마신 술 표시. 사진 없으면 주종 고양이 이미지 |
| 2 | **기록 작성** | 주종 선택 / 술 이름 / 마신 날짜 / 사진 / 평가 / 테이스팅 노트 / 한줄평 |
| 3 | **검색** | 주종별 그리드 + 술 이름 텍스트 검색 + 날짜 범위 검색 |
| 4 | **주류 추천** | 규칙 기반 스코어링 1종 |
| 5 | **내 정보** | 통계 차트 + 뱃지 + 닉네임/프로필 사진 |

### 데이터
- Room DB — 주종 / 술 / 기록 / 테이스팅 노트 / 노트 연결 테이블
- **시드 데이터** 주종 8종 + 술 20~30종 + 테이스팅 노트 항목을 앱에 직접 내장
- 사진은 내부 저장소(filesDir)에 파일 저장, DB에는 경로만
- 닉네임·프로필 사진은 **DataStore** (Room 아님)

### 기술
- Kotlin / XML 레이아웃 + ConstraintLayout + View Binding
- Single Activity + Fragment 5개 + BottomNavigationView
- Room (`@Query`에 SQL 직접 작성) / Coroutines + Flow / ViewModel + StateFlow / Repository
- RecyclerView 직접 구현 (캘린더 격자 포함, 라이브러리 없음)
- Glide (이미지), MPAndroidChart (차트)

## 🚧 범위 확장이 떠올랐을 때 체크리스트

1. 이게 없으면 **핵심 화면 5개 중 하나가 동작하지 않는가?** → 아니면 OUT
2. 강의 커리큘럼에 **이미 배울 주차가 잡혀 있는가?** → 있으면 OUT (수업에서 배우면 됨)
3. 예상 소요가 **2시간을 넘는가?** → 넘으면 `docs/TODO-future.md`로
4. 그래도 하고 싶으면 → **IN 목록에서 무엇을 뺄지 먼저 정한다**

## 📉 시간이 부족할 때 버리는 순서

일정이 밀리면 아래 순서로 **위에서부터** 잘라낸다.

1. 뱃지 시스템
2. 내 정보의 통계 차트 (MPAndroidChart)
3. **주류 추천 화면 전체** ← 여기까지 버려도 프로젝트는 성립한다
4. 캘린더 → 날짜순 RecyclerView 리스트로 대체

**절대 버리지 않는 것**: Room DB 설계·구현, `docs/` 문서화 (이게 이 프로젝트의 목적)
